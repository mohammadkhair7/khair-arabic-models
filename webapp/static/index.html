    About عن المشروع

    alarabia.chat runs four compact neural models for classical Arabic — diacritization, part-of-speech tagging and text-structure segmentation — trained without a single manually labelled example.

    The models are open source Apache 2.0

    Every model, the code that trained it, and the data it learned from are published and free to download: github.com/qurancomp/khair-arabic-models. They are small enough to run on a CPU, so you can host this yourself.

    Your text is not kept

    • Uploads are processed in memory and never written to disk.
    • Results are held only long enough for you to download them, then discarded.
    • No account, no tracking, no analytics, no third-party scripts.
    • Every upload is type-checked, size-capped and screened for malicious content before it is opened.
